## 🌟 About The Project

Khazinti Web serves as the primary digital storefront and transparency portal for the **Khazinti Mobile Application**, it introduces users to the app's powerful financial tracking features.

The platform provides an engaging **Home** experience, a legally compliant **Privacy Policy**, and a fully automated, interactive **Changelog** timeline showcasing the history of Khazinti's development.


## 🚀 Tech Stack

- **Framework**: Vue 3 (Composition API)
- **Build Tool**: Vite
- **Routing**: Vue Router
- **Localization**: Vue I18n
- **Deployment**: GitHub Actions & GitHub Pages
- **Icons**: Pure Unicode / Custom SVGs

## 🛠️ Development Setup

To get a local copy up and running, follow these simple steps:

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Medkhalilbs/khazinti-web.git
cd khazinti-web

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```
## 📦 Build & Deployment

This project uses **GitHub Actions** for CI/CD. Every push to the `main` branch automatically builds the Vue application and deploys the `dist/` directory to the `gh-pages` branch.

**Manual Build:**
```bash
# Build for production
npm run build

# Preview the production build locally
npm run preview
```
